# v1.0.0 — proposed portfolio release notes

**DRAFT — not published.** These notes accompany Issue #99 and are subject to
final CI verification and release approval. `v1.0.0` has not been tagged.

## What is included

- Python-based market data ingestion and validation with PostgreSQL-backed
  analytics / Gold processing, protected by opt-in execution controls.
- Apache Airflow 3.1.7 scheduling and a seven-task DAG, paused by default.
- Read-only Streamlit dashboard with Overview, Market charts, Indicators and
  Pipeline monitoring pages.
- Local Docker Compose setup, safe startup/health diagnostics, offline Airflow
  and dashboard smoke checks, PostgreSQL integration tests, and seven GitHub
  Actions quality gates.
- Operator guidance for secrets, least privilege, backup/recovery, and
  portfolio verification.

Local smoke/build/test outcomes are recorded in

## Boundaries and known limitations

- Portfolio and local-development demonstration only: no hosting, production
  SLA, brokerage integration, trading advice, registry publication or automated
  production deploy.
- Real provider ingestion / Gold writes are disabled by default; populated data
  requires local configuration and explicit, safe permission. Private API keys,
  `.env`, and datasets are not included.
- Base container images are tag-referenced and Python dependency versions are
  ranges; bit-for-bit reproducibility is not claimed. No verified SBOM,
  vulnerability scan, signed images or release provenance attestation.
- Dashboard is read-only. HTTP startup and offline AppTest checks do not prove
  successful live SQL reads, full browser rendering or production readiness.
- M10 timing measurements vary with machine, and evidence review does not prove
  database rollback. Rollback of container images does not undo database writes.
